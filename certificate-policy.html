Certificate policy

Version 2026-08-14

What is awarded

A signed-in learner becomes eligible after all 18 modules are recorded complete. The learner must then choose a public display name, review the disclosure, and explicitly claim and publish the certificate.

What it demonstrates

The certificate demonstrates completion of the Java Basecamp path and its 135 listed concepts. Completion is learner-recorded and is not a supervised examination or identity-verified skills assessment.

How verification works

Each certificate receives an unguessable public ID, a credential ID, and a unique 64-character verification code. A public result is valid when those values match an active record in the Java Basecamp PostgreSQL database.

The verification code is a database identifier. It is not a blockchain record, digital signature, government credential, or third-party accreditation.

Privacy and withdrawal

The public page shows the chosen name, course, issue date, credential ID, and verification code. It does not show an email address. Learners can unpublish and later republish the same certificate from their account.

Corrections and issuer action

Learners can correct their displayed name. The issuer may suspend public verification for abuse, impersonation, technical error, or manipulated progress. A certificate remains subject to these terms and the privacy notice.

This is not an Oracle certification. Java Basecamp is independent and is not affiliated with, endorsed by, or sponsored by Oracle. Java is a trademark of Oracle and/or its affiliates.
