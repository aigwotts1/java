# Java Basecamp

A friendly, visual Java learning roadmap covering the 17 modules in the supplied curriculum reference—from syntax and OOP through Spring, JVM internals, testing, and interview-focused DSA.

## Run locally

This is a dependency-free static site. Open `index.html` directly, or serve the folder with any local server:

```powershell
python -m http.server 4173
```

Then visit <http://localhost:4173>.

## Features

- Responsive dimensional UI built with HTML, CSS, and JavaScript
- Search and stage filters across 90+ concepts
- Interactive module previews and practice challenges
- Progress tracking saved in the browser with `localStorage`
- Keyboard-accessible cards, dialog, and `/` shortcut for search
- Reduced-motion support
